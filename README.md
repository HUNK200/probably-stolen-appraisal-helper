# 深空当铺 · 智能鉴别手册 Mod

> 鉴别物品时，自动把对应的鉴别手册摆到屏幕左侧，省掉在鉴别界面和手册之间来回翻的操作。

**状态：** 需求梳理完成，尚未开始编码
**性质：** 非官方兴趣项目 · AI 辅助开发

---

## 这是什么

《深空当铺：可能是偷的》（Probably Stolen）里，鉴别物品靠的是**玩家自己读手册、自己下判断**。原版流程要求在鉴别界面和手册之间反复切换，很打断节奏。

这个 Mod 不改变任何原版规则，只做一件事：**玩家开始鉴别时，把对应的那本手册直接摆到屏幕左侧。**

## 目标功能（第一版）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| R01 | 自动检索手册 | 扫描玩家背包 + 当前可操作的文档柜 |
| R02 | 自动匹配手册 | 根据正在鉴别的物体找到对应手册 |
| R03 | 自动展示 | 复用原版手册界面与文本，固定在屏幕左侧 |
| R04 | 快捷键 | 打开 / 关闭 / 翻页（键位待定） |
| R05 | 缺少手册提示 | 找不到时提示玩家，不生成、不伪造手册 |

## 设计原则

1. **不改原版规则** —— 不碰物品获取、交易和鉴别逻辑。
2. **玩家自主判断** —— 不自动识别物品等级，不代替玩家鉴定。
3. **原版界面优先** —— 复用原版手册的展示形式，不重做内容。
4. **访问范围受限** —— 只查玩家当前能访问的存储位置。
5. **需求驱动** —— 不提前臆测游戏内部机制。

## 技术栈

| 项 | 结论 | 说明 |
| --- | --- | --- |
| 引擎 | Unity 2021.3.45f2 | 实机确认 |
| 脚本后端 | **Mono**（非 IL2CPP） | 有 `MonoBleedingEdge/` + `_Data/Managed/Assembly-CSharp.dll`，无 `GameAssembly.dll` |
| Mod 形式 | **游戏原生 Mod**（`IMod` + manifest） | 不走 MelonLoader；根目录 `Mods/` 为游戏自带 |
| 依赖 | 游戏自带 `0Harmony.dll`、`DseCecil.dll`、Newtonsoft.Json | 可直接引用游戏程序集 |
| 日志 | 待确认 | |

> **一次关键更正：** 最初依据社区资料判定为 IL2CPP + MelonLoader，实机检查证明是 **Mono + 原生 Mod 框架**。这个差别很大——省掉了 Cpp2IL / Il2CppInterop 整条链路，也避免了加载器与游戏版本绑定带来的崩溃风险。
>
> **版本风险：** 游戏 2026-10-28 发售，仍在高频更新，`Assembly-CSharp.dll` 会随补丁变动；每次验证都需要记录游戏版本号。
