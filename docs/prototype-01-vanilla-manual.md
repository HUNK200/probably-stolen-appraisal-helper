# 原型验证 01：只用原版手册观察（零代码、零安装）

> 目的：在写第一行代码前，用游戏**原版自带的鉴定指南**把 R03/R04 的行为摸清楚，把不确定性提前消掉。
> 需要：进游戏操作约 15 分钟。
> 不需要：装 Mod、编译、改任何文件。

---

## 为什么要做这一步

`docs/mod-api-notes.md` 里的 API 是从社区指南读来的，**没有在真机上验证过**。其中三条直接影响需求能不能落地：

| 待验证 | 影响的需求 | 如果结论是「否」 |
| --- | --- | --- |
| 手册面板能否停留在屏幕一侧、与其它界面共存 | R03 自动展示 | 整个方案要改（只能做快捷键唤出） |
| 面板能否被脚本摆到指定位置 | R03 「固定左侧」 | 只能用 `posX` 默认值，不能自适应 |
| 翻页/关闭是否是面板自带的能力 | R04 快捷键 | 要自己实现翻页 |

## 前置准备

1. 启动游戏，停在主菜单，**记下主菜单上显示的版本串**（形如 `100-Rev14`）——这个数字后面每次验证都要写进记录。
2. （可选）在游戏根目录（与 `Probably Stolen.exe` 同级）新建一个**空文件** `dev.txt`，这样进入游戏后按 `F8` 能打开调试控制台、按 `F9` 能打开开发菜单。
   - 这是**写入游戏目录**的操作，由你自己做，我不代劳。
   - 有了 `F8` 控制台，后面的日志排查会方便很多。

## 观察清单

> 每一条都请按「现象」记录，不要按「应该是」。有截图更好。

### Q1 手册在背包里长什么样

- 打开背包，找到鉴定指南（初级鉴定师应该就有一本）。
- 记录：物品名、图标长什么样、鼠标悬停的提示文字。
- 关键：**它是普通物品，还是有独立的「文档」分类？**

记录：

```
物品名：
图标描述：
提示文字：
是否有分类标记：
```

### Q2 打开手册后面板在哪、能不能动

- 从背包打开手册。
- 记录：
  - 面板出现在屏幕的哪个位置（偏左 / 居中 / 右侧）？
  - 能不能拖动？
  - 能不能缩放（滚轮 / 按钮）？
  - 有没有关闭按钮？快捷键能不能关？

记录：

```
初始位置：
可拖动：是 / 否
可缩放：是 / 否
关闭方式：
```

- **重点观察**：手册打开时，右边的鉴别/交易界面**还能不能操作**？还是被挡住了？
  这一条决定了「左侧展示」到底有没有意义——如果原版打开手册就会挡住整个界面，那我们的核心价值才成立。

### Q3 翻页行为

- 翻到第 2 页、第 3 页，再往回翻。
- 记录：
  - 一共几页？
  - 末尾再点「下一页」会怎样？（卡住 / 循环回第一页）
  - 页码显示在哪？
  - 翻页有音效吗？
- **这一条直接回答 `project.md` 第 5 章里的两个待定项**：「翻页是否支持循环」「是否记忆上次阅读页」——原版怎么做的，我们大概率跟着做。

记录：

```
总页数：
末页行为：
首页往回翻：
页码位置：
```

### Q4 能否同时打开多本手册

- 如果你有多本手册（不同等级 / 不同类型），试着同时打开两本。
- 记录：第二本打开时，第一本是关掉了、被覆盖、还是并排显示？

记录：

```
同时打开两本：
```

### Q5 开始鉴定时，游戏会不会自己打开手册

- 正常做生意，等一位顾客带来需要估价的物品。
- 记录：
  - 鉴定时游戏有没有自动弹出/提示手册？
  - 如果没有任何自动行为，说明 R01/R02 确实是我们要补的价值（好事，需求成立）。
  - 如果有，记录它是什么形式（提示条？按钮？）。

记录：

```
是否自动展示：
形式：
```

### Q6 手册能放进文档柜吗

- 找到文档柜（如果此时还没有，可以跳过，标记「暂无条件」）。
- 记录：手册能放进去吗？放进去之后从柜子里能直接打开吗？打开时要不要先把柜子打开？

记录：

```
能否放入：
柜内能否直接阅读：
```

## 观察记录（2026-11-12 实机，VERSION 100-REV13）

```

Q1 手册物品：手册属于「文档」类物品。

Q4 多本共存：不能同时打开多个，打开下一本会覆盖上一本。
Q5 鉴定时是否自动展示：不会。→ R01/R02 的需求成立

补充现象：
- F8 控制台打不开（F9 有 Debug panel）。
```

### 由实测得出的结论

| 结论 | 影响的待定项 |
| --- | --- |
| 手册是「文档」类物品 | R01 检索有明确的对象类型可依 |
| 打开下一本会覆盖上一本 | 「多手册冲突」「切换物体时旧面板去留」在原版里是覆盖语义，跟着做最省事 |
| 翻页不循环、首页不后退 | 「翻页是否支持循环」原版即不支持 |
| 鉴定时不会自动展示 | R01/R02 确实是本项目要补的价值，不是重复造轮子 |
| 手册可放入文档柜并能直接阅读 | R01 的「文档柜」这条路径存在，值得做 |

### 仍未确认

- **Q2 的追问**：手册打开时，右侧的鉴别/交易界面还能不能操作？（这决定「左侧展示」是不是真需求）
- F8 控制台为什么打不开；日志能否从 `%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\Player.log` 读
- 手册面板「出现位置不固定」是谁决定的（上次关闭位置？鼠标位置？）
