# 原型验证 02：自制手册能否稳定停在左侧

> 目的：确认 R03「把手册固定到屏幕左侧」到底是**改个坐标就行**，还是**得自己托管面板**。
> 这是整个项目最后一个未知数——验证完，实现路径就定了。
> 前提：`mods/appraisal_helper` 已启用（验证 01 已通过）。

---

## 为什么先做这个

验证 01 已经确认：原版手册会**挡住**右侧鉴别界面，必须拖开才能操作。这意味着：

- 需求成立：自动把手册摆到左边确实有价值。
- 但原版「每次出现位置不固定」，所以我们**必须自己指定位置**，不能依赖原版。

关键问题是：这个位置好不好控制？三种可能，对应三条完全不同的实现路线。

| 观察到的情况 | 说明 | 后续路线 |
| --- | --- | --- |
| `posX/posY` 能精确控制，且能贴近屏幕左边缘 | 最理想 | JSON 配置即可，几乎零代码 |
| 能控制但会受窗口分辨率影响 | 可接受 | 代码里按 `Screen.width` 动态算 |
| 面板位置被原版逻辑覆盖，改了也不生效 | 最麻烦 | 需要在打开后强行 `SetPosition`，甚至自己托管面板 |

## 操作步骤

> 纸质手册**只存在于商店场景**，所以必须先载入一个存档。

### 1. 打开纸质手册编辑器

1. 载入一个存档，进入店里。
2. 按 `F9` → 左列 `Special` → `Modding Panel` → `Paper Editor`。

### 2. 新建一本测试手册

在 **Book** 标签页的 *New book* 下：

| 字段 | 填什么 |
| --- | --- |
| 模组 | 选 `Appraisal Helper` |
| ID | `test_guide` |
| 起点模板 | 选**「鉴定指南」**那一项（便于直接对比原版） |

点 **Create and edit**。它会写入并打开：

```
<游戏目录>\Mods\appraisal_helper\Books\test_guide.json
```

### 3. 把它拖到屏幕最左边缘

- 直接拖动面板本身，尽量贴住左边，但**不要超出屏幕**。
- 松手后等 1 秒（编辑器会自动保存）。

### 4. 记录四个值

在右侧 **Inspector** 里找这本书的位置字段（可能叫 `posX` / `posY`，也可能是 X / Y）：

```
posX =
posY =
```

如果找不到字段，跳过，我从 JSON 文件里读。

另外记录（能答多少答多少）：

```
屏幕分辨率（游戏设置里看）：
面板宽度大概占屏幕几分之几：
拖动之后有没有自动弹回原位：
```

### 5. 多翻几页确认外框还在

确认翻页按钮、页码、关闭按钮都正常——这些是原版外框提供的，我们后面要沿用。

### 6. 退出编辑器，汇报

**不需要**重新部署、不需要改代码。做完把上面几个值贴给我即可。

## 我会做什么

拿到 `posX` 之后：

1. 我读一遍 `Mods/appraisal_helper/Books/test_guide.json`（只读）；
2. 把实际字段结构记进 `docs/mod-api-notes.md`，替换掉「待确认」；
3. 把 `posX` 的取值方案（固定值 vs 按分辨率计算）定下来，写进需求的 R03；
4. 然后开始写第一段真正的功能代码：**在合适时机 `OpenPaper` 并设置位置**。
